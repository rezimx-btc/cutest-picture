# Make the cutest picture

Entry for the make.fun bounty "Make the cutest picture"
(https://make.fun/bounty/cutest-picture-01).

`main.py` copies the bundled picture (`hedgehog.png` — a tiny baby
hedgehog in a knitted scarf, sitting in a teacup in make.fun brand
colors covered all over with repeated "make.fun" logo text, among
soap bubbles) to `/output/entry.png`. Deterministic: the same bytes
on every run. No network, no randomness.

Run: `python3 main.py` (Python 3.13). Output: `/output/entry.png`.
